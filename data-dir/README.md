Dataset is placed here.
The following directory structure is expected:

```tree
data-dir/
├── grasps/
├── mesh2sdf-nglod-600k/
└── meshes/
```

`grasps` and `meshes` are from the [ACRONYM](https://github.com/NVlabs/acronym) dataset while `mesh2sdf-nglod-600k` is generated from `meshes` by the [pre-processing routine](../README.md#preparation).
